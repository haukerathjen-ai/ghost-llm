# 👻 Ghost LLM

> **Designed by Human | Developed by AI**

A revolutionary voice-controlled AI assistant that seamlessly integrates speech recognition, vision processing, and intelligent automation - brought to life entirely through AI-generated code.

---

## 🌟 Vision

Ghost LLM represents a groundbreaking experiment in human-AI collaboration. **100% of the codebase was generated by AI** (Claude 3.5 Sonnet), while a human architect provided the vision, requirements, and quality control. This project demonstrates that with clear direction and iterative feedback, AI can produce production-ready, complex software systems.

**The Mission:** Create an invisible assistant that listens to your voice commands, understands your screen context, and types intelligent responses directly into any application - no copy-paste, no context switching.

---

## ✨ Features

### 🎙️ **Voice-to-Action**
- High-quality audio capture using SoX audio engine
- **Local Whisper Large-v3** with GPU acceleration (CUDA)
- **Automatic Cloud Fallback** when GPU is unavailable
- Support for multiple languages (optimized for German)
- Hotkey-activated recording (Ctrl+Shift+G / Ctrl+Alt+G / F9)

### 👁️ **Vision-Context Awareness**
- Automatic screenshot capture during voice commands
- Screen content analysis via Claude 3.5 Sonnet with Vision
- Context-aware responses based on what you're working on
- Perfect for code reviews, documentation, and content creation

### ⌨️ **Ghost Typing**
- Seamless text insertion directly into active applications
- Natural typing simulation with configurable speed
- No clipboard pollution - types character by character
- Works with any application (IDE, browser, text editor)

### 🧠 **Intelligent Strategies**
- **Coder Strategy**: Generates code snippets and technical solutions
- **Formatter Strategy**: Improves text formatting and structure
- **Summarizer Strategy**: Creates concise summaries of content
- Extensible architecture for custom strategies

### 🎨 **Modern Dashboard**
- Real-time status monitoring
- System health indicators (Audio Engine, API connectivity)
- Recording history and activity tracking
- Elegant UI with glassmorphism design

## 🚀 Quick Start

### Prerequisites

- **Node.js** 18+ and npm
- **Windows 10/11** (primary platform)
- **OpenAI API Key** (for Whisper transcription)
- **Anthropic API Key** (for Claude 3.5 Sonnet)
- **SoX Audio Engine** (for high-quality audio recording)

### 1. Install SoX

Download and install SoX for Windows:
- **Official Download**: https://sourceforge.net/projects/sox/files/sox/14.4.2/
- Choose: `sox-14.4.2-win32.exe` or `sox-14.4.2-win64.exe`
- During installation, **check "Add to PATH"**
- Restart your terminal after installation

**Verify installation:**
```bash
sox --version
```

### 2. Clone & Install

```bash
git clone https://github.com/haukerathjen-ai/ghost-llm.git
cd ghost-llm
npm install
```

### 3. Configure API Keys

Create a `.env` file in the root directory:

```env
# OpenAI API Key (for Whisper transcription)
OPENAI_API_KEY=sk-...

# Anthropic API Key (for Claude 3.5 Sonnet)
ANTHROPIC_API_KEY=sk-ant-...
```

### 4. Launch

```bash
npm run dev
```

The application will start:
- Next.js Dashboard: http://localhost:3000
- Electron Window: Opens automatically

## 🎯 Usage

### Basic Workflow

1. **Activate Recording**: Press `Ctrl+Shift+G` (or `Ctrl+Alt+G` / `F9`)
2. **Speak Your Command**: e.g., "Write a function to calculate fibonacci numbers"
3. **Stop Recording**: Press the hotkey again
4. **Ghost Types Response**: Watch as the AI types the answer into your active application

### Example Commands

**Coding:**
- "Explain this code" (while viewing code on screen)
- "Write a Python function to parse JSON"
- "Add error handling to this function"

**Writing:**
- "Summarize this article" (while viewing article)
- "Improve the grammar of this paragraph"
- "Write a professional email reply"

**Analysis:**
- "What does this error message mean?" (with error visible)
- "Review this code for bugs"
- "Extract key points from this document"

## 🔧 Troubleshooting

### Audio Engine Issues

If you see `⚠️ Audio-Engine (SoX) nicht gefunden`:

1. **Verify SoX is installed:**
   ```bash
   sox --version
   ```

2. **Check PATH environment variable:**
   ```bash
   echo %PATH%
   ```
   Should include SoX directory (e.g., `C:\Program Files (x86)\sox-14-4-2`)

3. **Manual test:**
   ```bash
   sox -t waveaudio -d -r 16000 -c 1 -b 16 test.wav trim 0 5
   ```
   Speak for 5 seconds, then check `dir test.wav` (should be > 50KB)

### Microphone Permissions

If recording produces silence or "Amara.org" hallucinations:

1. **Windows Settings** > Privacy > Microphone
   - Enable "Allow apps to access your microphone"
   - Enable "Allow desktop apps to access your microphone"

2. **Sound Control Panel** > Recording
   - Set the correct microphone as Default Device
   - Check volume levels (minimum 70%)

3. **Test in Windows Voice Recorder** first to verify microphone works

For GPU setup and CUDA troubleshooting, see [SETUP_CUDA_GPU.md](SETUP_CUDA_GPU.md).

## 📊 Performance

- **Audio Quality**: 16kHz, 16-bit, Mono (Whisper-optimized)
- **Transcription**: ~3-5 seconds for typical commands
- **Vision Analysis**: ~2-4 seconds with Claude
- **Typing Speed**: Configurable (default: 50ms/char)
- **Total Response Time**: ~5-10 seconds end-to-end
